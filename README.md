# 🎵 MP3 Tag Reader & Editor

A C programming project designed to read, display, and edit metadata stored in MP3 audio files using ID3 tags.

## 🚀 Features

- View MP3 metadata, including title, artist, album, and other supported fields.
- Edit supported metadata fields.
- Read and write binary files using C file-handling functions.
- Parse ID3 headers and metadata frames.
- Handle Big-Endian frame-size bytes using bitwise operations.
- Organize functionality into modular C source and header files.

## 🛠️ Technologies Used

- C Programming
- File Handling
- Structures and Arrays
- Bitwise Operators
- Binary File Processing
- Modular Programming

## 🧠 Key Learning

This project helped me understand binary file operations, ID3 tag structure, byte manipulation, and metadata processing in C.

One important implementation was decoding a four-byte Big-Endian frame size into an integer using bitwise shifting and OR operations.
